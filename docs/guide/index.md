# Operator guide

This guide covers CAEN DT5202 boards connected through a DT5215 concentrator.
The documentation describes the software revision from which it was built;
check the installed DAQ revision before applying instructions from a newer build.

1. Follow the [operator manual](../operator-user-manual.md) for setup, connection, and a first run.
2. Learn to [interpret telemetry](telemetry.md), including freshness and rate estimates.
3. Check [temperatures and HV](temperatures-and-hv.md) before and during acquisition.
4. Review [trigger configuration](triggers.md) and [hardware caveats](caveats.md).
5. Use the [hardware recovery procedures](../hardware-operations.md) if acquisition fails.

For saved data, see the [HDF5 examples](../hdf5-schema-examples.md).
For scanning, see [source scans](../source-scans.md).
